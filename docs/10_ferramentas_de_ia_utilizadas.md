## 10. Ferramentas de IA Utilizadas

### 10.1 Copilot (GitHub)

**Uso:** Autocomplete de código, sugestões de implementação para componentes React e serviços NestJS.

**Decisão:** Usar Copilot para acelerar o desenvolvimento, mas revisar e ajustar cada sugestão.

### 10.2 ChatGPT (OpenAI)

**Uso:** Discussão de arquitetura, geração de trechos de código complexos, depuração de erros.

**Decisão:** Usar ChatGPT como consultor, mas validar todas as sugestões com testes e revisão manual.

### 10.3 Gemini (Google)

**Uso:** Discussão de arquitetura, geração de trechos de código complexos, depuração de erros.

**Decisão:** Usar Gemini como consultor, mas validar todas as sugestões com testes e revisão manual.

### 10.4 O que foi feito sem IA

- **Design system:** As cores, espaçamentos e componentes visuais foram desenhados manualmente.
- **Fluxo de navegação:** A lógica de rotas e proteção foi pensada manualmente.
- **Decisões de produto:** A escolha de portaria como usuário criado pelo organizador, download de ingresso em vez de compartilhamento, e rota aninhada para compra foram decisões humanas.
